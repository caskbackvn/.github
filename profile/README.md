# CaskBack

CaskBack (caskback.vn) là nền tảng đổi link mua sắm để nhận hoàn tiền theo hình thức cashback.

CaskBack là tên thương hiệu của nền tảng; cashback là hình thức hoàn tiền mua sắm.

## Tính năng

- Đổi link sản phẩm từ Shopee, Lazada và TikTok Shop.
- Xem tiền hoàn dự kiến trước khi mua hàng.
- Theo dõi tiền hoàn và tìm mã giảm giá.
- Rút tiền miễn phí về ngân hàng từ 10.000đ khi số dư đủ điều kiện.

Tiền hoàn thực tế phụ thuộc sản phẩm, giá thanh toán và điều kiện ghi nhận của từng sàn.
